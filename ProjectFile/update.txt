# SIM800L ESP32 Platform - Project Update & Transition Guide (`update.txt`)

## 📌 Update Objectives & Milestones
Transform the platform from an open single-operator tool into an enterprise-ready, multi-tenant telecommunication platform with:
1. User Authentication & RBAC (Admin, Manager, Moderator, User).
2. Modern Next.js 16 Fullstack Dashboard (100% English, Mobile-Responsive).
3. Targeted Voice Broadcasts (Specific MAC, Virtual IDs, Anonymous #31# Cloak).
4. Virtual Device Dedicated Addresses & Cumulative Talk Duration Tracking.
5. Accurate Telco Carrier Signaling Feedback (UDUB Rejected, Call Waiting, Forwarded, Busy, Connected).
6. Zero-Drop Priority FIFO Queue under Heavy Server Load (Automatic 3x Backoff Retry).
7. Comprehensive Call Management & Date-to-Date CSV Report Generator.
8. Automated Call & SMS Campaign Engine with Calendar Scheduling.
9. Granular Device Activity Audit History ("Who did what, when, and what changed").

## 📋 3. Master Implementation Checklist

### Backend & Database (`Server/`)
- [x] **User Authentication & JWT Middleware**:
  - `POST /api/auth/signup`, `POST /api/auth/login`, `GET /api/auth/me`.
  - Roles: `admin`, `manager`, `moderator`, `user`.
- [x] **Extended Mongoose Models**:
  - `User`: Credentials, roles, assigned devices.
  - `DeviceProfile`: Physical MAC, labels, groups, allowed users.
  - `VirtualDevice`: Dedicated virtual address, cumulative talk duration, total calls, total SMS.
  - `EspJob`: Target phone, contact name, route type, virtual ID, anonymous cloak, duration, carrier feedback, queue position, retry attempts.
  - `DeviceActivityEvent`: Audit logs of every configuration change and call/SMS event.
- [x] **Zero-Drop Priority FIFO Queue Engine**:
  - Buffers excess calls into `queued` state with `queuePosition`.
  - Automatically pops next job as modems free up.
  - 3x auto-retry with backoff for busy or waiting lines.
- [x] **Telco Carrier Signaling Parser**:
  - Detects `ANSWERED`, `REJECTED` (UDUB Release Cause 17), `CALL_WAITING` (CW), `FORWARDED` (Voicemail), `BUSY`, and `UNREACHABLE`.
