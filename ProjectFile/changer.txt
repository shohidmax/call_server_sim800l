### C. Zero-Drop Priority Queue & Carrier Feedback Worker
- **Queue Buffering**: When active calls reach hardware concurrency limit, incoming requests are marked `status: 'queued'` and given an incremental `queuePosition`.
- **FIFO Dispatch**: As channels complete calls, the worker dequeues the lowest `queuePosition`.
- **Auto-Retry Backoff**: Calls returning `busy` or `call_waiting` are rescheduled up to 3 times before final marking.
- **Virtual Device Talk Time Accumulation**: Whenever a call on a virtual address completes, `totalCallDurationSeconds` on that virtual device is incremented by the exact call duration.

### N. End-to-End USSD Subsystem & Unicode/UCS2 Decoding Overhaul
- **Firmware Engine (`Farmwire/callServer.ino`)**:
  - Engineered robust `executeUSSD(code)` function.
  - Prepends `AT+CUSD=2` to cancel hung interactive USSD sessions (resolving `+CME ERROR: 512`).
  - Sets standard character set (`AT+CSCS="GSM"`).
  - Implements automatic DCS parameter fallback: attempts `AT+CUSD=1,"<code>",15` and retries `AT+CUSD=1,"<code>"` if DCS=15 is rejected by the operator network.
  - Fixed premature string truncation by verifying both opening and closing quotation marks on incoming `+CUSD: <m>,"<str>",<dcs>`.
  - Added unsolicited asynchronous `+CUSD:` handling in `simBuffer` loop.
  - Added target `mac` and `code` attributes in `esp32_cmd_result` Socket.IO events.
- **Backend Relay (`Server/server.js`)**:
  - Added `decodeUssdPayload(raw)` regex parser to convert 16-bit UCS2 hex responses into readable Unicode (Bengali/English) text.
  - Broadcasts decoded string in `dashboard_cmd_result` as `data.decoded`.
- **Frontend Live Terminal (`web/src/context/DataContext.tsx` & `/devices/[mac]`)**:
  - Transformed `triggerUssd` into a real `Promise<string>` with 22-second GSM network safety timer.
  - Eliminated mock `setTimeout` that displayed fake static account balance; now displays the real carrier response directly on the USSD console.
  - Logs USSD responses into the device activity audit trail.
